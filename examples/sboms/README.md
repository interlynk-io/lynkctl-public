## Reproduce

Install the approved v0.3.6 binary first. The fixed checkout path below matches the published evidence paths. Use a fresh directory; a different path can change path-bearing fields and hashes.

```sh
mkdir -p /tmp/lynkctl-public-sources
git clone https://github.com/FreeRTOS/FreeRTOS.git /tmp/lynkctl-public-sources/FreeRTOS
cd /tmp/lynkctl-public-sources/FreeRTOS
git checkout --detach f4fcc3b228643144727e9257ba12db1cb632b6e6
git submodule update --init FreeRTOS/Source

lynkctl generate FreeRTOS/Demo/CORTEX_STM32F103_IAR/RTOSDemo.ewp \
  --provider iar --iar-config Debug --project-root . \
  --no-oss-index --disable-os-enrichment --no-map \
  --include-source-files --exclude-header-files --evidence \
  --reproducible --timestamp 2026-09-19T00:00:00Z -v \
  > ../freertos-stm32f103.cdx.json 2> ../freertos-stm32f103.diagnostics.txt

lynkctl generate FreeRTOS/Demo/CORTEX_STM32L152_Discovery_IAR/RTOSDemo.ewp \
  --provider iar --iar-config Debug --project-root . \
  --no-oss-index --disable-os-enrichment --no-map \
  --include-source-files --exclude-header-files --evidence \
  --reproducible --timestamp 2026-09-19T00:00:00Z -v \
  > ../freertos-stm32l152.cdx.json 2> ../freertos-stm32l152.diagnostics.txt
```

The kernel submodule is pinned to `3a22924e0a9ddbbc8b0758881c33b3422a5cc20d`. Each provenance file records the exact argument array and output SHA-256. Both examples passed CycloneDX 1.6 schema validation and produced identical bytes in two consecutive runs in the same checkout.
