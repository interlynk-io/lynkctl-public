# Contributing

Contributions to documentation, public examples, CI templates, and benchmark methodology are welcome through pull requests. Implementation requests can be discussed in issues; lynkctl itself is proprietary.

For an example, include a public upstream URL, pinned revision and submodules, exact command and generator version, selected configuration, raw SBOM, diagnostics, exit code, and SHA-256. Validate against the official CycloneDX schema and explain missing evidence. Submit only materials you have permission to publish, and review generated paths and metadata before sharing.

Benchmark submissions must follow [the protocol](benchmark/README.md) and retain failed runs and uncertainty. Do not submit credentials, customer firmware, or private build logs.
